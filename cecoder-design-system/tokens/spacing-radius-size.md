# 间距 / 圆角 / 尺寸 Spacing · Radius · Sizing

## 间距 Spacing

| 变量 | 值 | 常用场景 |
| --- | --- | --- |
| `--cds-space-*` / `--semi-spacing-tight` | 8px | 紧凑内/外边距，图标与文字间距 |
| `--cds-space-*` / `--semi-spacing-base-tight` | 12px | 默认偏紧凑，卡片内边距 |
| `--cds-space-*` / `--semi-spacing-base` | 16px | 默认内/外边距，表单项之间 |
| `--cds-space-*` / `--semi-spacing-loose` | 24px | 宽松间距，区块之间 |
| `--cds-space-*` / `--semi-spacing-extra-loose` | 32px | 大区块间距 |
| `--cds-space-*` / `--semi-spacing-super-loose` | 40px | 页面级留白 |

完整间距阶梯（→ Layer2 别名）：

| 级别 | 值 | Cecoder |
| --- | --- | --- |
| none | 0 | `--cds-space-0` |
| super-tight | 2px | `--cds-space-1` |
| extra-tight | 4px | `--cds-space-2` |
| tight | 8px | `--cds-space-3` |
| base-tight | 12px | `--cds-space-4` |
| base | 16px | `--cds-space-5` |
| base-loose | 20px | `--cds-space-6` |
| loose | 24px | `--cds-space-7` |
| extra-loose | 32px | `--cds-space-8` |
| super-loose | 40px | `--cds-space-9` |

## 圆角 Radius

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--cds-radius-card` | 8px | **卡片固定圆角（规范）** |
| `--cds-radius-xs` | 3px | Checkbox 内圆角 |
| `--cds-radius-sm` | 3px | Button/Tag/Tabs 等大多数组件 |
| `--cds-radius-md` | 6px | Dropdown/Transfer 菜单类 |
| `--cds-radius-lg` | 12px | Modal |
| `--cds-radius-circle` | 50% | Avatar/Badge 圆形 |
| `--cds-radius-full` | 9999px | 胶囊标签 |
